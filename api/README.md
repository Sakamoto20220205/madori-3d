# 間取り3D

手書きの間取り図をもとに部屋を作り、寸法を指定した家具（ベッド・机・椅子・棚など）を置いて、平面図と3Dで確認できるWebアプリです。1つのHTMLファイルだけで動きます。

## 使い方
1. `index.html` をブラウザで開く（GitHub Pagesでも公開できます）
2. ① 部屋の寸法：部屋の形を選び、幅・奥行き・ドアなどを数字で入力
3. ② 家具を置く：よく使う家具を押す、またはサイズを決めて作る。図の上でなぞって移動
4. ③ 保存・印刷：自動保存。配置案に名前を付けて残せる。A4横の印刷用画像を作れる

## 仕様メモ
- 単位はすべてcm
- 保存先はブラウザのlocalStorage（端末ごと）
- 3D表示は three.js r128（CDN読み込み）
